# MatchDay Booking Website

## About the Project
MatchDay Booking is a responsive sports match booking website developed using HTML and CSS.

## Features
- Responsive navigation bar using Flexbox
- Booking form and summary arranged using CSS Grid
- Responsive layout for desktop and mobile screens
- Horizontally scrollable booking table on smaller screens
- Media queries for different screen sizes

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
